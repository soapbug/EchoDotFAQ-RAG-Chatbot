# EchoDotFAQ-RAG-Chatbot
Built an FAQ chatbot using Retrieval-Augmented Generation (RAG) to answer product-specific questions about Amazon Echo Dot.
Implemented semantic search with OpenAI embeddings and Chroma vector database for grounded document retrieval.
Integrated LangChain to manage prompt templates, context injection, and constrained LLM response generation.
# EchoDotFAQ — RAG-Based FAQ Chatbot

EchoDotFAQ is a Retrieval-Augmented Generation (RAG) chatbot designed to answer frequently asked questions about Amazon Echo Dot devices. The system combines embedding-based semantic search with large language model generation to produce grounded, context-aware responses based on official documentation and customer review data.
